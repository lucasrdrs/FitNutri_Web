# FitNutri Web

Projeto final de curso (acadêmico) que propõe um sistema para **aproximar o nutricionista do cliente**.

## Sobre o projeto

Para um nutricionista, acompanhar de perto cada cliente é difícil. O FitNutri nasceu para tornar esse acompanhamento mais próximo e contínuo, conectando o profissional ao cliente em um só lugar.

Este repositório contém a versão **web** do projeto. A primeira versão foi desenvolvida em C# e está em [FitNutri_Front](https://github.com/lucasrdrs/FitNutri_Front).

## Tecnologias

- HTML
- CSS
- JavaScrit

## Estrutura do repositório

- `telas/`: páginas do sistema
- `imagens/`: imagens usadas nas páginas

## Como executar

Baixe ou clone o repositório e abra os arquivos da pasta `telas/` no navegador.
Abra pelo login.html.
